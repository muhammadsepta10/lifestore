# Prototipe layar kasir (#20)

PROTOTIPE, buang setelah dipakai. Satu berkas HTML (`prototipe-kasir.html`). Buka langsung di browser, tanpa instalasi.

Pertanyaan yang dijawab: seperti apa layar kasir di tablet/PC? Halaman ini menampilkan tiga variasi tata letak di atas data dan logika yang sama. Pindah variasi dengan bilah di bawah atau tombol panah ← →.

- A · Denah meja dulu: denah meja sebagai layar utama, tagihan di panel samping.
- B · Tiga kolom POS: daftar tagihan terbuka, grid menu, dan tagihan aktif berdampingan.
- C · Papan per kanal: kartu pesanan per tahap, dengan input cepat lewat keyboard.

Semua variasi bisa mencoba:
- input pesanan dengan varian
- kirim ke dapur
- batal item dengan PIN atasan
- pesanan ojol manual
- pisah tagihan
- bayar campuran dengan pembulatan tunai
- mode offline (QRIS dinamis mati, ada antrean Sinkron)
- tutup shift dengan Hitung Buta

Data hanya disimpan di memori.
